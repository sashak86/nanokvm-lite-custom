# NanoKVM Lite · Sipeed × Sasha

Независимая кастомная сборка на основе **Sipeed NanoKVM 2.5.2**. Производитель устройства и автор исходного приложения — [Sipeed](https://github.com/sipeed/NanoKVM), кастомизация — [Sasha / sashak86](https://github.com/sashak86). Не официальный релиз Sipeed.

## Что меняется

- Наш интерфейс открывается по основному адресу с телефона и компьютера; после входа возвращается автоматически. Стоковый вид: `/?classic=1` или «Устройство → Обычный вид».
- Верхние кнопки 72×64, модификаторы 64×64, функциональные клавиши ≥88×88; ряды прокручиваются. Полупрозрачная плашка (opacity 0.24).
- Логотип и favicon «Sipeed × Sasha»: голубой монитор с S-монограммой и оранжевым акцентом. Логотип виден в кнопке «Устройство» и панели сведений; favicon — в нашем, классическом интерфейсе и форме входа.
- Тачпад, клавиатура, MJPEG/H.264, загрузка ISO/IMG, собственный overlay автозагрузки. Серверный бинарник производителя не изменён.

## Пакет и проверка

[Релизы и ZIP](https://github.com/sashak86/nanokvm-lite-custom/releases). ZIP — пакет приложения и кастомного overlay, **не образ SD-карты**. Внутри `latest/` — оригинальное приложение Sipeed 2.5.2, `custom/` — наш слой. Файлы устройств и пароли в пакет не включаются.

Перед установкой сравните SHA256: `sha256sum -c nanokvm-custom-2.5.2-c4.zip.sha256`. Не используйте пакет для NanoKVM Pro/PCIe или других устройств без проверки совместимости.

## Установка

Скопируйте ZIP на NanoKVM Lite, распакуйте в отдельный каталог и перейдите в него. Для обновления уже работающего NanoKVM с нашим overlay:

```sh
sh install.sh --ui-only
```

Обновляет `/root/custom`, `/etc/init.d/S94kvmcustom` и обе web-копии (`/kvmapp/server/web`, `/tmp/server/web`). Службы, USB/HID и режим диска не перезапускает. Обновите вкладку браузера. Именно этот путь проверен на c4.

Первая установка overlay на обычное приложение 2.5.2: `sh install.sh`, затем плановая перезагрузка. Автозагрузка также блокирует автообновление с cdn.sipeed.com и включает заводской режим, в котором подключённый сервер видит раздел ISO только на чтение; `kvmcustom-watch` поддерживает этот режим. Заводское приложение, сеть и пароли обычная установка не заменяет. Базовая загрузка NanoKVM занимает около 3 минут.

`sh install.sh --full` заменяет всё `/kvmapp` приложением из ZIP. **Этот режим не проверен на живом устройстве**; для обновления интерфейса он не нужен.

## Откат обновления интерфейса

Установщик печатает путь `/root/nanokvm-backup-<дата>-<pid>`. В нём прежние `custom/`, `S94kvmcustom`, `permanent/` и `runtime/`. Верните их соответствующие `m.html`, `index.html`, `branding/` в исходные каталоги и прежний `/etc/init.d/S94kvmcustom`; перезапуск для UI не нужен. Если `branding/` до обновления отсутствовал, удалите только добавленный каталог. Для полного удаления overlay сохраните собственные пользовательские изменения: удалите S94, восстановите заводские `index.html` и `/etc/hosts` из заранее сохранённых копий (`/root/index.html.stock`, `/root/hosts.stock`, если они есть), удалите `/boot/usb.disk0.ro` и перезагрузите. Не удаляйте флаг, если он нужен вашей конфигурации диска.

## Исходники и сборка

`m.html`, `custom/`, `branding/` — весь наш слой. `build-package.sh c4 2.5.2` загружает оригинальный пакет из CDN Sipeed с проверкой SHA512 и добавляет слой; результат — `dist/` (не в git). Версия на CDN может измениться; проверка ожидаемой версии предотвращает незаметную замену базы.
